# 555 Arcade 0.1.0-beta.1

First public preview of the canonical `555 Arcade` plugin.

## Included

- unified arcade package surface for auth, session, games, score, leaderboard, and quests
- public ecosystem docs linkage
- action and operator documentation
- public-preview skills for operators and OpenClaw-style agents
- CI validation and release-check coverage

## Public preview scope

- session bootstrap
- game catalog, play, switch, stop
- score, leaderboard, and quest surfaces
- live gameplay through `ARCADE555_GAMES_GO_LIVE_PLAY`

## Known limitations

- not GA
- advanced admin, GitHub, and Alice-only mastery surfaces are not first-run public setup paths
- broader gameplay mastery remains a separate track from plugin public release
